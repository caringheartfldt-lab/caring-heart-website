# Caring Heart Foundation Website v3

A redesigned bilingual English/Chinese static website for Caring Heart Foundation.

## Design changes
- Inspired by the professional, structured Evergreen seniors-site style: page banners, mission/vision/value cards, compact sections, clear CTAs and consistent spacing.
- Softer Caring Heart logo-inspired palette using lavender/rose, blue, green and warm coral.
- No black header or footer backgrounds; the logo's dark lettering remains readable.
- Color-shifting gradient backgrounds and subtle floating effects add visual depth without making the site distracting.
- Smaller, more restrained typography for a senior-focused audience.
- Responsive mobile navigation.
- English/Chinese switch with localStorage.
- Light/dark mode with a dark navy/green/purple theme rather than black.
- Shared assets are organized into:
  - `assets/css/`
  - `assets/images/`
  - `assets/images/photos/`
  - `assets/videos/`
  - `assets/js/`

## Important before launch
- Replace placeholder contact information.
- Connect forms to a secure backend/form service.
- Connect donation buttons to a secure, reputable donation processor.
- Verify the Foundation's legal/tax status and public disclosures before publishing claims about tax deductibility or IRS determination.
- Have any regulated care/health/insurance services reviewed by qualified professionals and implement required licenses/policies before offering those services directly.
- Add photo/video assets to `assets/images/photos/` and `assets/videos/` as the site grows.
