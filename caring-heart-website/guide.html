WEBSITE GUIDE

Caring Heart Foundation Website Guide

A practical guide for updating the website, managing languages, adding photos and videos, and preparing the site for publication.

1 / QUICK START

How the website is organized

🏠

index.html

The home page. Update the main welcome message, priorities, featured programs and calls to action here.

📄

pages/

Contains the About, Programs, Events, Volunteer, Contact, Donation, policy and individual program pages.

🎨

assets/css/

Shared visual design. style.css controls colors, typography, layout, cards, buttons, responsive behavior and dark mode.

⚙️

assets/js/

Shared behavior. app.js controls language selection, saved preferences, dark mode, mobile navigation and demo forms.

2 / LANGUAGES

English, Simplified Chinese and Hong Kong Traditional Chinese

For website visitors

Use the language selector in the upper-right corner to choose English, 简体中文, or 繁體中文. The selection is remembered when moving between pages.

For content editors

Each translatable element normally uses data-en, data-zh and data-zh-hk. Keep all three attributes when changing a sentence.

4 / PHOTOS & VIDEOS

Adding your own media

assets/images/photos/

  1. Copy optimized JPG, JPEG, PNG or WebP photos into this folder.
  2. Use descriptive file names, for example 2026-senior-university.jpg.
  3. Add an appropriate alt description when placing a photo in HTML.

assets/videos/

  1. Place local video files here if you decide to host them yourself.
  2. For large videos, consider YouTube or another video platform instead of storing large files in GitHub.
5 / EDITING

Basic editing workflow in VS Code

1

Open the project

Open the caring-heart-website folder in VS Code.

2

Edit content

Change the appropriate HTML page. For translated text, update all three languages together.

3

Test locally

Open index.html in Chrome and test navigation, language selection, dark mode, buttons and mobile layout.

4

Publish

Commit and push the changed files to your hosting repository, then verify the published site.

6 / BEFORE LAUNCH

Important items still requiring real services

💳 Donation

The current donation page contains placeholder actions. Connect a secure donation processor before accepting payments.

📝 Forms

Contact and other forms currently use demo behavior. Connect them to a secure backend or form service.

⚖️ Compliance

Verify organizational, tax, solicitation, privacy and any regulated-service requirements before publishing final claims or accepting donations.

📷 Media consent

Obtain appropriate permission before publishing identifiable photos or videos of participants, especially seniors.
